# MacroSnap 🍎

MacroSnap is an AI-powered nutrition tracking application that analyzes food
images and provides estimated calories and macronutrients such as protein,
carbohydrates, and fats.

## Features

- 📸 Upload food images
- 🤖 AI-based food recognition
- 🔥 Calorie estimation
- 💪 Protein, carbohydrate, and fat analysis
- 📊 Simple and user-friendly interface

## Tech Stack

- Python
- Streamlit
- AI / Computer Vision
- Nutrition Analysis

## Installation

Clone the repository:

git clone <your-github-repository-url>

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Live Demo

https://macrosnap-heufbe.streamlit.app/

## Usage

1. Open the application.
2. Upload an image of your meal.
3. Let the AI analyze the image.
4. View the estimated calories and macronutrient information.
